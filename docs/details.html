Technical details and paired uncertainty

This page keeps replication data available without asking every reader to understand tokens, cache behavior, or agent-loop internals before they understand the experiment.

Terms used in the results

Run / attempt

One fresh agent context working on one language variant. Attempts do not share memory.

Pass

The final service satisfied the full external behavioral verifier, including concurrency, stale writes, deletion, errors, and regressions.

6/6 passed

Six separate agent attempts were run in that condition and all six passed. This is not a count of test cases.

Agent step

One model action in the linear mini-swe-agent loop. It can contain shell commands, inspection, edits, or verification work.

Output tokens

Tokens generated by the model. This is a rough measure of response volume, not code quality.

Cache hit rate

The share of input tokens served from the provider cache. It mostly matters for cost and runner debugging.

Known limitations

This is one model snapshot, one bash-only agent scaffold, three backend contracts, and three attempts per task-language cell. It does not test long-term maintenance, browser applications, dependency migrations, or human review. Language is a treatment bundle that includes topology and toolchain differences.
