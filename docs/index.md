# Language AI Bench

Language AI Bench gives a coding agent equivalent software-engineering tasks in
different programming languages and grades the final behavior with a shared
verifier. Earlier cohorts saturated: in v0.6 all 36 attempts passed, which makes
any language contrast unreadable. v0.7 adds one deliberately hard brownfield
family, `money-rollup`, and runs it at two model strengths. On the strong rung 42
of 48 attempts passed. No pass-rate contrast excludes zero, but Go needed 1.3 to
1.7 more agent steps than each other language, with all three intervals
excluding zero. Cohorts are never pooled across studies.
